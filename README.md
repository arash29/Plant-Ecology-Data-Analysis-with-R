# Plant Ecology Data Analysis with R

## About this project

This repository documents my practical work with R for ecological data analysis, with a focus on botany, plant diversity and community ecology.

The project aims to develop and strengthen reproducible workflows for analysing floristic and ecological datasets.

## Main objectives

- Data import, cleaning and management
- Descriptive statistics and scientific visualization
- Species richness and diversity indices
- Community composition and multivariate analysis
- Relationships between vegetation and environmental variables

## R packages

The main packages used in this project include:

- **tidyverse:** data management and visualization.
- **vegan:** community ecology and biodiversity analysis.
- **readxl:** importing Excel datasets.

Additional packages will be introduced as the project develops.

## Project organization

The repository will progressively include R scripts, example datasets, figures and analytical reports.
